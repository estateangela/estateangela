### 🤖 `> projects`
- 🗺️ **[rn-route-audit](https://github.com/estateangela/rn-route-audit)** — published on the [GitHub Marketplace](https://github.com/marketplace/actions/react-navigation-route-audit)

Maps React Navigation routes to the screens that render them, and finds a route from text someone read on screen. Validated against BlueWallet, Rocket.Chat and react-navigation itself · 75 tests · zero dependencies.</sub>

- 🌐 **[i18n-key-audit](https://github.com/estateangela/i18n-key-audit)** — published on the [GitHub Marketplace](https://github.com/marketplace/actions/i18n-key-audit)
  <br><sub>Finds the translation problems that never fail a build: a key used in code that no locale defines, so the user reads the raw key, and keys one locale has that another is missing. Designed by measuring three real projects first — every non-base locale in all three was incomplete.</sub>
